Legenda notazione UML per le relazioni
	--|>   ereditarietà        (extends)
	..|>   realizzazione       (implements)
	◇--    aggregazione        (rombo vuoto): il "tutto" contiene riferimenti a elementi che possono esistere anche da soli (es. iniettati via costruttore)
	◆--    composizione        (rombo pieno): il "tutto" possiede in modo esclusivo la parte, solitamente creandola al proprio interno; la parte muore con il tutto
	molteplicità es.: 1 : 0..1  |  1 : 0..*  |  1 : 1

Classe NodeDTO: rappresenta un singolo nodo dell'albero.

	Ereditarietà: (classe base, nessuna superclasse)

	Relazioni di aggregazione/composizione:
		◆-- composizione (self-associazione): NodeDTO ◆── 1 : 0..* children : NodeDTO
		   ogni nodo possiede in modo esclusivo i propri figli (children = new ArrayList<>()); la lista è creata
		   nel costruttore e i figli vengono aggiunti via addChild(). Struttura ricorsiva ad albero.

	Attributi
	- leaf: boolean
	- splitCondition: String {null se nodo foglia}
	- predictedValue: Double {null se nodo interno}
	- selected: boolean {= true di default}
	- children: List<NodeDTO>

	Metodi
	+ NodeDTO(splitCondition: String)
	+ NodeDTO(predictedValue: Double)
	+ setLeaf(leaf: boolean)
	+ isLeaf(): boolean
	+ setSplitCondition(splitCondition: String)
	+ getSplitCondition(): String
	+ setPredictedValue(predictedValue: Double)
	+ getPredictedValue(): Double
	+ getChildren(): List<NodeDTO>
	+ addChild(child: NodeDTO)
	+ toString(): String
	+ isSelected(): boolean
	+ setSelected(selected: boolean)


Classe TreeDTO: rappresenta l'albero decisionale (radice + tabella associata).

	Ereditarietà: (classe base, nessuna superclasse)

		   un TreeDTO possiede la radice del proprio albero; la radice, a sua volta, possiede i figli
		   (catena di composizione con NodeDTO).

	Attributi

	Metodi

Classe MainController: orchestratore delle operazioni (listener, avvio worker).

	Ereditarietà: (classe base, nessuna superclasse)

	Relazioni di aggregazione/composizione:
		◇-- aggregazione: MainController ◇── 1 : 1 view : MainFrame
		   la vista è iniettata nel costruttore e il suo ciclo di vita è gestito dal chiamante; il controller
		   ne mantiene solo il riferimento.
		◆-- composizione: MainController ◆── 1 : 1 connection : ServerConnection
		   la connessione è creata dal controller (new ServerConnection()) e condivisa con i worker
		   come riferimento in lettura (i worker non la possiedono).
		(dipendenze) usa i pulsanti di ControlPanel tramite view.getControlPanel(); istanzia i worker:
		   InitTreeWorker, PredictionWorker, TableLoaderWorker (relazione di creazione/uso)

	Attributi
	- view: MainFrame
	- connection: ServerConnection

	Metodi
	+ MainController(view: MainFrame)
	- initListeners()
	- handleInitTree()
	- handlePredict()
	- handleRefreshTables()

Classe PredictionWorker: worker di una sessione di predizione interattiva.

	Ereditarietà:
		--|> javax.swing.SwingWorker<Double, NodeDTO>

	Relazioni di aggregazione/composizione:
		◇-- aggregazione: PredictionWorker ◇── 1 : 1 connection : ServerConnection (iniettata, condivisa)
		◇-- aggregazione: PredictionWorker ◇── 1 : 1 view : MainFrame (iniettata, condivisa)
		◆-- composizione: PredictionWorker ◆── 1 : 0..1 rootNode : NodeDTO
		   l'albero "decision path" viene costruito dal worker durante la navigazione.
		◆-- composizione: PredictionWorker ◆── 1 : 0..1 currentNode : NodeDTO
		   ramo corrente lungo l'espansione dell'albero.
		(dipendenze) crea istanze di NodeDTO e TreeDTO; usa javax.swing.JOptionPane per le domande all'utente.
		(usa) composizione/creazione di TreeDTO passato poi a TreePanel via view.

	Attributi
	- connection: ServerConnection
	- view: MainFrame
	- rootNode: NodeDTO
	- currentNode: NodeDTO
	- visitedConditions: List<String>

	Metodi
	+ PredictionWorker(connection: ServerConnection, view: MainFrame)
	# doInBackground(): Double
	- handleOkResponse(): Double
	- handleQueryResponse(step: int): void
	- parseBranchOptions(queryText: String): List<String>
	- promptUserForChoice(queryText: String): int
	# process(chunks: List<NodeDTO>)
	# done()
